# Diagramas de Casos de Uso — Atlas Contábil

Este documento apresenta os diagramas de casos de uso organizados por módulo do sistema **Atlas Contábil**, com descrições resumidas para contextualização.

---

## Módulo 1 — Acesso ao Sistema

Este diagrama representa as funcionalidades relacionadas ao acesso do usuário ao sistema Atlas Contábil. Inclui o cadastro de novos usuários, autenticação por login e encerramento de sessão, garantindo controle de acesso às funcionalidades principais do aplicativo.

Este diagrama apresenta as funcionalidades responsáveis pela navegação e organização visual da interface do sistema. Engloba a exibição da tela inicial, navegação entre telas e atualização visual das informações conforme as interações realizadas pelo usuário.

Este diagrama demonstra as funcionalidades responsáveis pela visualização geral do sistema. Inclui o acesso ao dashboard, painel inteligente com calendário, tarefas e insights, além da exibição de mensagens informativas ao usuário.

## Módulo 5 — Gestão Inteligente de Tarefas

Este diagrama apresenta as funcionalidades relacionadas ao gerenciamento inteligente de tarefas do sistema. Inclui a visualização de tarefas organizadas por data, atualização de status, definição de prioridades, geração de insights inteligentes, geração de resumo diário e filtragem de tarefas por dia.
